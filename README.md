# LectureNotesAI (MVP-ready skeleton)

This repository contains a full project skeleton for LectureNotesAI:
- backend (FastAPI)
- nlp_engine (transcription & summarization placeholders)
- frontend (static templates)
- database helpers
- scripts, tests, and docs

Follow docs/installation.md to set up venv and install dependencies.

## Frontend

The frontend is built with React and TypeScript. To run the frontend:

```bash
cd /path/to/project
npm install
npm run dev
```

The frontend will be available at http://localhost:3000
